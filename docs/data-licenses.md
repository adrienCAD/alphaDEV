## Software licenses (affects what can be public)
- open-DARTS: **GPL-3.0-or-later**. Importing it from a public pipeline has copyleft implications; avoid unless you accept GPL for that code.
- JutulDarcy: license not confirmed on the pages read; check its GitHub repo.
- OPM Flow: license not stated on the OPM home page; check the repo.
